# AI-review presentation and request context

Production remains Russian. Optional default-RU locale props prepare AI-review copy only; letters/career and other remaining views/global English acceptance are still open. No model setting, inference endpoint, provider prompt, quota, schema or permission is changed.

Errors store semantic keys for HTTP status, invalid success JSON/envelope/citations, interruption, network and safe fallback. HTTP failures take precedence over body parsing; provider/exception text is never shown. Locale changes re-render existing consent, pending/result/error state without replay. A synchronous active-request guard prevents duplicate requests before a render. Owner or canonical revision changes remount the bound request state and reset consent/result/errors; unmount aborts the old request, clears the timer and excludes late UI updates. This does not guarantee cancellation of inference already submitted to a server.

The existing strict owner/revision envelope and eligible-fact/exact-quote validator remain unchanged. Quotes and fact text/IDs are not translated. Exact citations establish provenance, not semantic truth or competence; results do not change score, profile or saved versions. The existing backend requires explicit consent for each request and stays off by default. Translating consent copy is not an operator decision about lawful data location/retention and does not authorize live testing or third-party LLM transmission.

Development uses immutable GitHub files/Git objects and leased ref updates because the local executor remains unavailable. CI results will be recorded after completion; no local execution is claimed. Eight new actual-component browser cases cover bilingual consent/pending/result/canonical body/no duplicate request, late HTTP HTML failure, malformed success JSON/invented evidence/manual retry, owner/revision changes, timeout/network/unexpected-exception redaction, and leaving the editor with a newer dirty draft. A semantic HTTP-feedback unit case covers status handling. Existing production-route/envelope/quote tests remain required.

Fixtures intercept requests and use hardcoded SYNTHETIC sources. A synthetic English mobile screenshot is emitted into CI logs for visual review with axe/overflow checks. This does not prove an available or accepted model; no real inference, mail, paid infrastructure, production migration, hh.ru write, merge or release is performed. Live own-model evaluation, SMTP/recovery, Supabase provider-copy restore/RPO/RTO, operator data decisions, manual/PWA/global bilingual and final acceptance remain open.
