Locale changes do not clear or regenerate manual text, caret/selection, selected facts, style or approval. Editing text clears approval as before; changing style/facts intentionally resets the draft/approval as before. Leaving the editor or changing the workspace revision still unmounts the draft, now stated in copy. No automatic save/send or persistence is added.

New source-dirty and paused-action gates disable fact/style/generation/template restoration/approval/download while retaining local text and state. The textarea remains editable, and typing still clears approval. Returning to exactly the same saved fields re-enables actions; a changed saved source/revision follows the existing remount lifecycle. Action handlers guard export/generation as well as buttons. This does not claim semantic verification of manually rewritten text.
