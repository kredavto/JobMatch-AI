# JobMatch: текущий preview MVP

Сценарий: **загрузить файл резюме → проверить распознанный текст → загрузить вакансию по ссылке → адаптировать → скопировать резюме и письмо для ручного отклика**.

Тестовая версия: https://jobmatch-ai-git-feat-simple-mvp-20261108-digagency.vercel.app/

Ветка `feat/simple-mvp-20261108`, Vercel project `jobmatch-ai`. Публикация в эту ветку не означает готовность Production или полноценной генеративной адаптации.

## Как пользоваться

1. Выберите файл резюме: **Word (.doc или .docx), TXT, RTF, PDF или PNG**. Вставка текста вместо файла недоступна. Вход в hh.ru не нужен.
2. Проверьте распознанный текст, особенно цифры, даты и имена на сканах. Ошибки исправьте в исходном файле и загрузите его заново. Резюме можно использовать без сохранения либо сохранить как локальный профиль. Старые профили, созданные вставкой текста, нужно заново загрузить файлом; сохранённые версии не удаляются.
3. Введите HTTPS-ссылку на вакансию и нажмите **«Загрузить вакансию»**. Для hh.ru используется официальный API с серверным токеном приложения. Вход соискателя не требуется.
4. Нажмите **«Адаптировать резюме»**. Результат получает точное название вакансии; исходные формулировки сохраняются, релевантные пункты могут подниматься только внутри безопасно распознанных списков. Письмо использует исходные цитаты.
5. Проверьте результат и нажмите **«Копировать: Текст адаптированного резюме»** / **«Копировать: Текст сопроводительного письма»**. Если браузер запрещает буфер обмена, доступно **«Выделить весь текст»** и обычное копирование через меню устройства.
6. Перенесите текст в свой аккаунт hh.ru и отправьте отклик самостоятельно. Приложение не сохраняет резюме в hh.ru и не отправляет отклики.

При загрузке файла приложение извлекает текст, а не копирует исходное оформление. Для PNG и страниц PDF без читаемого текстового слоя используется распознавание русского и английского текста. На первом скане браузер скачивает файлы распознавания с адреса JobMatch, но не отправляет сам документ. Заблокированные паролем, повреждённые и слишком большие документы нужно заменить.

На мобильном экране предусмотрена кнопка **«Скачать приложение на смартфон»**: она вызывает доступное браузерное предложение установки либо показывает инструкции. Это веб-приложение/ярлык, не APK и не приложение из магазина. Наличие кнопки и headless-проверка не доказывают фактическую установку на телефоне.

## Что означает «адаптация» сейчас

Главный экран вызывает детерминированную функцию непосредственно **в браузере**. Файл и извлечённый текст не покидают браузер при чтении, распознавании или обычной адаптации. Отдельный ограниченный ИИ-пилот, где доступен, отправляет извлечённый текст только по явно запрошенному действию после согласия. Сопоставление навыков ищет явные упоминания, не оценивает квалификацию и не присваивает балл 0–100. Не найденный навык не означает его отсутствия у человека: словоформы и неоднозначные формулировки могут не совпасть.

Новые навыки, даты и достижения не добавляются. Отрицания, планы, контактные строки и распознанные инструкции не используются как положительные цитаты; исходник сохраняется. Это осторожный лексический фильтр, а не доказательство истинности и не полная семантическая проверка.

**Свободное ИИ-переписывание личного резюме не включено.** `/rewrite-demo` показывает только сохранённый ответ одного теста Groq на вымышленных фактах. Страница не вызывает модель, не читает локальные профили, не принимает и не применяет предложения. Демо открывается отдельно, не уничтожая несохранённый основной результат. Числа и точные ссылки на источник не гарантируют сохранения авторства, ролей, единиц или смысла.

Серверные адаптеры Groq/Ollama/Vercel AI Gateway остались для изолированных экспериментов. Флаги окружения не включают внешний ИИ в текущем публичном workflow и не заменяют разрешение на обработку реальных данных. Передача данных hh API стороннему провайдеру отдельно ограничена; согласие на резюме не снимает это ограничение. Одноразовый синтетический build-time smoke удалён; постоянных вызовов модели при сборке нет.

## Профили и приватность

- До **5 профилей**, до **100 000 символов** текста в каждом, с дополнительным общим ограничением сериализованного хранилища. Запись проверяется на возможность последующего чтения.
- Сохранение выполняется только явной кнопкой в `localStorage` этого браузера и адреса сайта. Нет аккаунта JobMatch, облачной синхронизации, БД профилей или резервной копии.
- Локальные данные **не зашифрованы**. Не сохраняйте их на общем устройстве. Не загружайте документы с паспортными, медицинскими и другими лишними чувствительными сведениями.
- По отдельной кнопке «Сохранить как отдельную версию» можно сохранить до 3 снимков: точный исходник, адаптированный текст и письмо. Это отдельное согласие на хранение, не автоматическое сохранение; профиль не меняется. Сравнение доступно до сохранения, снимки можно открыть после обновления страницы и скопировать.
- Версии не зашифрованы, доступны только в этом браузере и удаляются отдельно. Удаление профиля НЕ удаляет снимки его исходника: предупреждение показано и в описании, и перед удалением профиля. Лимит не вытесняет старые снимки автоматически. Повреждённое хранилище, конфликт вкладок и переполнение не перезаписываются молча.
- Очистка данных сайта удаляет профили и версии. Несохранённый текст и результат исчезают после закрытия/обновления страницы или ухода с неё. Храните исходник отдельно.
- Удаление профиля требует подтверждения; ошибки хранилища не выдаются за успешное сохранение. Очевидные изменения из другой вкладки не перезаписываются, но это не транзакционная многопользовательская БД.
- Копирование использует системный буфер: его синхронизация между устройствами зависит от ОС. Приложение не читает буфер для адаптации.
- Service worker кэширует только фиксированные публичные assets, не API, профили или результаты. Данные вакансии загружаются сервером; это не полностью офлайн-приложение.

## Доступ к вакансиям

Для hh.ru на сервере нужны `JOBMATCH_HH_APP_ACCESS_TOKEN`, `HH_USER_AGENT` и точный HTTPS `HH_APP_ORIGIN`. Секреты не должны иметь префикс `NEXT_PUBLIC_`, попадать в Git, клиент или логи. Настройки размещаются только в согласованном preview scope. Токен приложения читает вакансии, но не даёт доступ к списку, чтению или записи резюме соискателя.

Другие публичные HTTPS-страницы поддерживаются через JobPosting JSON-LD либо доступный текст страницы. Закрытые сайты, CAPTCHA, ограничения API, отказ доступа и страницы входа не обходятся. Автоматического повтора после запрета hh нет; новая попытка требует отдельного действия в UI.

## Разработка и проверки

Node.js 24, зависимости закреплены lockfile:

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run lint
npm run build
```

В репозитории есть pinned Playwright MVP-конфигурация. Для локальной production-сборки:

```sh
npm run build
npm run test:mvp:e2e
npx playwright test --config playwright.full-resume.config.ts
```

Для уже разрешённого preview (без обхода защиты deployment):

```sh
BASE_URL=https://jobmatch-ai-git-feat-simple-mvp-20261108-digagency.vercel.app npm run test:mvp:e2e
```

Если runner использует штатный установленный Chromium, `CHROMIUM_PATH` задаёт его путь. Тесты с viewport 390×844 и 375×812 используют синтетические данные (включая файлы резюме); отдельные сценарии мокают вакансию и события установки. Это не live-проверка API hh, не тест настоящего iPhone/Safari и не установка на физический телефон. Нельзя объявлять suite успешным, если браузер не запустился или среда заблокировала навигацию. [Последний mobile smoke](docs/MOBILE_SMOKE_20261119.md).

## История и границы

Старые серверные импорты, экспорт, hh OAuth/resume picker, Supabase-модули и миграции сохранены в коде, но **не являются текущим главным сценарием**. Наличие старого endpoint не доказывает его пригодности к публичной эксплуатации. Ранние документы могут описывать исторические этапы.

Локальные rate/concurrency limits работают на экземпляр приложения, не распределённо. Массовый публичный запуск требует отдельной эксплуатационной, security и правовой проверки; персональные данные на сервере и готовность Production здесь не сертифицируются.
