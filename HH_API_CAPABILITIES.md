# Проверка hh.ru API

Проверено: 2026-10-25. Источники:
- https://api.hh.ru/openapi/redoc
- https://api.hh.ru/openapi/specification/public
- https://github.com/hhru/api
- https://hh.ru/article/15116

Метаданные просмотренных операций и SHA256 полученной OpenAPI: docs/hh-operations.json. Матрица относится к сценарию соискателя, а не к полномочиям работодателя. Отсутствие публичного метода не доказывает отсутствие частного партнерского договора.

| Возможность | Статус для JobMatch | Основание / поведение |
|---|---|---|
| OAuth соискателя | permission required | Документирован механизм; нужны зарегистрированное приложение и разрешенные полномочия. В сборке отключен |
| Чтение вакансии | supported (документация), permission required (продукт) | Официальное чтение существует; без регистрации/проверки условий не включаем |
| Список собственных резюме | unavailable / не подтверждено | /resumes/mine не найден в полученной публичной OpenAPI; ручной импорт |
| Просмотр конкретного резюме | permission required | GET /resumes/{resume_id} документирован с OAuth; это не доказательство прав JobMatch на собственные резюме |
| Создание резюме | unavailable / не подтверждено | Публичная операция записи не найдена |
| Изменение резюме | unavailable / не подтверждено | PUT/PATCH резюме в проверенной публичной схеме не найдены |
| Публикация/поднятие резюме | unavailable / не подтверждено | Не активируется по историческим примерам |
| Отклики соискателя | unavailable / не подтверждено | /negotiations в текущей схеме описан для работодателя; не выдаем его за доступ соискателя |
| Просмотры/метрики соискателя | unavailable / не подтверждено | Наличие метрик работодателя не дает метрики пользователя; ручной трекер |
| Коммерческое применение | permission required | Регистрация и проверка конкретной модели; общего разрешения для этого продукта не установлено |

## Блокеры
Условия предусматривают регистрацию приложения (1.1), дополнительные условия онбординга соискателей (1.4), ограничение изменения полученных материалов (3.11), передачи API-данных сторонним сервисам (4.6), активных действий без согласия (4.9). Согласие соискателя само по себе не отменяет условия API. Нужны проверка договорной модели, прав обработки и требований к размещению данных; это не юридическое заключение.

## Fallback
Пользователь предоставляет собственный файл и текст вакансии. Оригинал не переписывается анализатором. Никаких скрытых API, CAPTCHA-обходов, scraping, паролей hh.ru, автопубликации или автооткликов. Подготовленный текст экспортируется для самостоятельного переноса через интерфейс hh.ru. Даже после получения OAuth запись нельзя включить одним флагом: потребуются документированный контракт, тесты и отдельное подтверждение конкретного diff.

## Следующая проверка
Перед включением интеграции повторно получить OpenAPI, проверить изменения схемы, роль каждой операции, текущие условия, разрешение приложения и коммерческую модель. Сгенерировать типизированный клиент только для подтвержденных операций. В MVP generated HH client не используется.
